## Brand & Style

This design system establishes an enterprise-grade cognitive operations environment tailored for Tier-3 support engineers, incident managers, and operations executives. The system centers on explainable intelligence: AI outputs are never presented as authoritative black boxes, but rather as grounded, inspectable syntheses supported by organizational memory.

The visual style blends **Corporate Modern** rigor with **Analytical Precision**:
- **Cognitive Ergonomics:** High data density balanced by disciplined typographic scale, clear visual anchors, and strict color semantics to prevent operator fatigue during critical incidents.
- **Explainability First:** Visual lineage indicators, confidence telemetry, and evidence breadcrumbs are native first-class citizens throughout the interface.
- **Architectural Clarity:** Flat, neutral foundational surfaces accented by deliberate, tinted micro-surfaces denoting cognitive machine synthesis versus validated human action.

## Colors

The palette leverages an authoritative indigo core grounded by slate infrastructure, with dedicated semantic accents for provenance tracking and cognitive telemetry:

- **Primary (`#4F46E5`):** Intelligence Indigo. Dictates interactive focus, active workflow pipelines, primary execution vectors, and core navigation highlights.
- **Secondary (`#0891B2`):** Evidence Cyan/Teal. Dedicated strictly to organizational memory references, grounded citations, knowledge base lookups, and graph linkages.
- **Tertiary (`#7C3AED`):** Synthesis Violet. Distinguishes generative recommendations, autonomous summarizations, and machine-suggested resolutions from human records.
- **Neutral Core (`#0F172A` / `#F8FAFC`):** Deep graphite text tokens paired with crisp, clean white surfaces and slate container structures (`#E2E8F0`, `#CBD5E1`).
